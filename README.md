## Python Pandas Analysis

### Tools Used
- Python
- Pandas
- Google Colab
- GitHub

### Analysis Results
- Total Revenue: ₹3,59,400
- Top-selling Product: Mouse
- Units Sold: 30
- Highest Revenue Product: Laptop
- Highest Product Revenue: ₹2,70,000

### Python Analysis
The sales data was analysed using Python Pandas.
Revenue was calculated using Quantity × Price.
Product-wise quantity and revenue were calculated
using Pandas groupby().
